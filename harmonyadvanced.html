和声进阶精讲

和弦结构 · 功能逻辑 · 编配思维 · 听觉训练

一、和声底层逻辑

1.1 三度叠置

现代和声的核心规则：以根音为起点，每次向上叠加三度（大三度或小三度）。

  • 根音 + 三度 + 五音 → 三和弦
  • 三和弦 + 七音 → 七和弦
  • 七和弦 + 九音 → 九和弦
  • 九和弦 + 十一音 → 十一和弦
  • 十一和弦 + 十三音 → 十三和弦
芦苇说 · 叠置逻辑
每叠一个三度，就像往房间多开一扇窗。三和弦是四面白墙，干净但不透气。七和弦是开了第一扇窗，风吹进来了。九和弦是第二扇，你能看见树了。十一和弦是第三扇，你看见了远山。十三和弦是屋顶也打开了——你看见了整片天空。但别忘了，好和声不是窗越多越好，而是每一扇窗开对位置。

1.2 三大功能组

功能和声的核心模型：T（主功能）→ S（下属功能）→ D（属功能）→ T

  • T（主功能）：I级、VI级，稳定、归家感，用于开头/结尾
  • S（下属功能）：IV级、II级，舒缓和声，用于叙事铺垫
  • D（属功能）：V级、VII级、属七，张力强，用于推动/转折
芦苇说 · 功能组
T-S-D-T 不是公式，是情绪的呼吸。T是你坐在家里，不说话。S是你站起来，走到窗边。D是你推开窗，风吹进来。T是你关窗，回到椅子上。清冷曲风为什么会“悬着”？因为我们故意让S和D之间拉得很长，或者让D迟迟不解决。情绪卡在半空中，就是欲言又止。

二、和弦分类完整版

2.1 三和弦（基础）

类型构造C调举例色彩使用频率
大三大三+小三C明亮、积极极高
小三小三+大三Am阴暗、内省极高
增三大三+大三C+扩张、紧张极低
减三小三+小三Bdim收缩、压抑低

2.2 七和弦（进阶主力）

类型标记C调音色用法
大七Maj7CM7空灵、温柔前奏、主歌、氛围
小七m7Am7忧郁、慵懒叙事、慢板
属七7G7紧张、推力副歌、转折、解决
半减七m7b5Bm7b5压抑、悲凉小调桥段、悬疑
减七dim7Cdim7对称、极紧过渡、转调

2.3 挂留和弦 Sus

去掉三音，用二度或四度替换，制造“悬停感”。

  • Sus2：根音 + 大二度 + 五音，极简清冷。例：Csus2（C-D-G）
  • Sus4：根音 + 纯四度 + 五音，悠远犹豫。例：Csus4（C-F-G）
  • 7sus4：属七+挂四，张力更复杂。例：G7sus4（G-C-D-F）

2.4 加音和弦 Add

保留三和弦，额外增加一个装饰音。

  • Add9：加九音，饱满文艺。例：Cadd9（C-E-G-D）
  • Add11：加十一音，轻盈透亮。例：Fadd11（F-A-C-Bb）
  • 6和弦：加六音，温暖复古。例：C6（C-E-G-A）

2.5 延伸和弦（高阶）

  • 属九（9）：G9（G-B-D-F-A），华丽、现代，R&B常用
  • 属十一（11）：G11，更空更悬，适合慢板铺底
  • 属十三（13）：G13，爵士终极收束音色
  • 大九（Maj9）：CM9，梦幻松弛，爵士主和弦首选
芦苇说 · 和弦层次
和弦每往上叠一个音，就像在夜里多看见一颗星。三和弦是月亮，够亮，但孤单。七和弦是月亮旁的第一颗星，你开始觉得夜空不是空的。九和弦是第二颗、第三颗——你看见了北斗。延伸和弦不是你主动加进去的，是你听见旋律需要它，它自己来的。好编曲不是会叠和弦，是知道什么时候该停。宁可少叠一颗星，不要堆到满天都是。

三、和弦替代体系

3.1 三全音替代（Tritone Substitution）

属七和弦被它增四度（三全音）距离的另一个属七替代。保留三全音张力，但低音变化。

G7 → Db7（共有的三全音：B-F）

原进行：Dm7 → G7 → Cmaj7

替代后：Dm7 → Db7 → Cmaj7（低音更顺，爵士味）

3.2 关系替代

用III级或VI级替代I级。共享两个共同音，和声更柔。

C → Em（共享E和G）

C → Am（共享C和E）

3.3 调式替代

同一根音，不同调式对应的和弦。如C大三被C大七或C利底亚替代。

C大调主和弦 → CM7、CM9、C△#11（利底亚色彩）

芦苇说 · 替代思维
和弦替代不是炫技，是换一种方式说同一句话。G7是“我走了”，Db7是“我走了”但走得更轻。C是“我好想你”，Em是“我好想你”但没说出口。替代是语气的变化，不是意思的变化。会替代的人，不是会更多和弦，是会更好地说话。

四、调式和声

4.1 教会调式速查

调式特征音色彩代表曲风
Ionian-明亮、自然标准大调流行
Dorian升VI忧郁但带一丝光爵士、Funk
Phrygian降II黑暗、异域弗拉明戈、金属
Lydian升IV梦幻、飘电影配乐、前奏
Mixolydian降VII摇滚、蓝调感摇滚、布鲁斯
Aeolian降III降VI降VII伤感、内省小调抒情
Locrian降II降V极不稳定几乎不用

4.2 调式和声的用法

  • 在同一个根音上切换调式，和声色彩会剧烈变化
  • 例：C大调主歌 → 桥段短暂切换到C多利亚（Ab→A），撕裂感
  • 国风五声调式避免半音，多用纯四/五度跳进，少用属七
芦苇说 · 调式
调式是光的颜色。Ionian是正午，Dorian是黄昏前，Phrygian是深夜，Lydian是凌晨天快亮的时候。学会调式不是让你换音阶，是让你选一束光。光选对了，和声自动有了情绪。

五、实战编配案例

5.1 C大调（温柔抒情）

基础：C → G → Am → F

大七升级：CM7 → G → Am7 → FM7

挂留留白：Csus2 → Gsus4 → Am7 → Fadd9

属七张力：C → G7 → Am → F

大九华丽：CM9 → G9 → Am9 → FM9

5.2 Am小调（清冷遗憾）

基础：Am → F → C → G

小七柔和：Am7 → FM7 → Cmaj7 → G7

极简空灵：Asus2 → F → C → Gsus2

情绪拉扯：Am7 → FM7 → Cmaj7 → E7

5.3 爵士II-V-I

C大调：Dm7 → G7 → Cmaj7

三全音替代：Dm7 → Db7 → Cmaj7

延伸版：Dm9 → G13 → Cmaj9

芦苇说 · 走向
好走向不是“对的”，是“自然”的。C-G-Am-F是直的，CM7-G-Am7-FM7是轻的，Csus2-Gsus4-Am7-Fadd9是慢的。同一句话，三种语气。和弦走向是你编曲的语气。语气对了，旋律不需要说太多。

六、听觉训练

  • 大三 vs 小三：C → Cm，从亮到暗，听中间那个音的变化
  • 大七 vs 小七：Cmaj7 → Cm7，从空灵到忧郁
  • 属七解决：G7 → C，感受“拉到家的张力释放”
  • 挂留解决：Csus4 → C，从“悬”到“落”
  • 替代听觉：Dm7 → G7 → Cmaj7 vs Dm7 → Db7 → Cmaj7，低音更顺
芦苇说 · 练耳
耳朵比乐理更重要。你能听出G7到C的“回家感”，比你能写出G7标记更重要。不要背和弦——去听和弦。听它们的呼吸、张力、颜色。耳朵会了，手自然会跟上来。
