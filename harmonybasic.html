一、大小调六大调式详解

核心：大小调各分3种，区别只在Ⅵ、Ⅶ级音的升降变化，主音、调号、主干音程框架不变。

1. 大调类（全全半全全全半）

  • 自然大调：无升降，明亮开阔。例：C D E F G A B
  • 和声大调：降Ⅵ级，幽暗伤感。例：C D E F G ♭A B
  • 旋律大调：下行降Ⅵ、降Ⅶ，柔和婉转。例：C D E F G ♭A ♭B

2. 小调类（全半全全半全全）

  • 自然小调：无升降，暗淡忧郁。例：A B C D E F G
  • 和声小调：升Ⅶ级，张力强、最常用。例：A B C D E F ♯G
  • 旋律小调：上行升Ⅵ、Ⅶ，下行还原。例：A B C D E ♯F ♯G
芦苇说 · 调式记忆
自然调式是底色，和声调式是戏剧感，旋律调式是流畅度。不必死背，记住一个口诀：小调升7是灵魂，大调降6添伤感。

二、大调体系编配（C大调）

2.1 自然大调

基础和弦：C、Dm、Em、F、G、Am

经典走向：C → F → G → C

2.2 和声大调（降Ⅵ级 → ♭A）

  • 特色和弦：♭A（♭VI）
  • 常用进行：C → F → G → ♭A（色彩突暗）
  • 避坑：♭A 后优先接 V(G) 或 I(C)

2.3 旋律大调（下行降Ⅵ、Ⅶ）

  • 特色和弦：♭A（♭VI）、♭B（♭VII）
  • 下行进行：G → ♭B → ♭A → F → C

三、小调体系编配（a小调）

3.1 自然小调

基础和弦：Am、C、Dm、Em、F、G

3.2 和声小调（升Ⅶ级 → ♯G）⭐ 最常用

  • 核心变化：v(Em) → V(E)（大三属和弦）
  • 万能进行：Am → F → E → Am

3.3 旋律小调

  • 流行简化：上行保留属和弦E，下行切回自然小调
芦苇说 · 小调核心
90%的流行小调歌曲用的其实是和声小调——只改一个音，把属和弦从小三变成大三，情绪立刻被拉起来。你听那些让你心口一紧的歌，大概率是E而不是Em。

四、流行常用调式走向库

4.1 自然大调

C大调：C → G → Am → F（万能卡农）

G大调：G → D → Em → C

F大调：F → C → Dm → Bb

D大调：D → A → Bm → G

4.2 自然小调（清冷/遗憾主力）

Am小调：Am → F → C → G（爆款小调走向）

Bm小调：Bm → G → D → A

Dm小调：Dm → Bb → F → C

4.3 中国民族调式（古风/国风/清冷核心）⭐

A羽调（五声）：Am → C → G → F（国风清冷万能走向）

G徵调（五声）：G → C → D → G

C宫调（五声）：C → G → F → C

芦苇说 · 清冷走向
你的曲风需要的不是复杂，是“空”。A羽调五声走向 Am→C→G→F，没有半音的拉扯，没有属七的紧迫，像风吹过芦苇，声音散了，情绪还在。
